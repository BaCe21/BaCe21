### [ARCore Geospatial VPS & GNSS Evaluation](https://github.com/BaCe21/arcore-geospatial-vps-evaluation)

Unity-based augmented reality research prototype developed as part of a master's thesis.

The application combines ARCore Geospatial tracking with GNSS measurements and real-world 3D spatial data.

- GNSS and VPS telemetry
- geospatial anchors
- QGIS-derived 3D models
- manual AR alignment
- CSV measurement logging
- compass and point-of-interest systems

### [Parallel Color Diffusion Simulation](https://github.com/BaCe21/colour-diffusion-parallel)

C++ project comparing several parallelization approaches on the same 2D diffusion workload.

- OpenMP
- MPI

The project focuses on parallel algorithm design, synchronization, boundary handling and performance benchmarking.

**Tech:** C++17, OpenMP, MPI, CUDA, CMake

### [Scanned Document Tampering Analysis](https://github.com/BaCe21/scanned-document-tampering-analysis)

Research pipeline developed for a master's thesis investigating character-level modifications in scanned documents.

The project combines OCR-based document processing with DCGAN training and quantitative evaluation of generated character samples.

**Tech:** Python, PyTorch, DCGAN, Tesseract OCR, computer vision
